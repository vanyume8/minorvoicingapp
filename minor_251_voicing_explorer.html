Manual — Minor ii-V-i Voicing Explorer
What is this app?

This tool generates four-note, one-handed minor ii-V-i voicings for all 12 keys, based on the formulas in Jazz Piano Fundamentals Book 2 by Jeremy Siskind. It is designed as a practice reference — configure your settings, see the voicings, and understand the finger movements between chords and between keys.

Controls
Start Voicing — Type A / Type B

Sets the voicing type for the first grid. Type A starts with the b3 as the bottom note; Type B starts with the b7. Subsequent grids auto-switch based on the interval rule (see below).

Key

Sets the starting minor key for grid 1. All 12 keys are available. Enharmonic pairs (e.g. F#/Gb) are shown together as a single button. The app uses the appropriate sharp or flat spelling for each key automatically.

Formula — HN / LN / R

Selects which of the three minor ii-V-i voicing formulas to use:

  • HN (Higher Ninth) — uses the higher (natural) 9th on the ii chord; the V chord uses the flat 13th. The i chord resolves to a minor 6th chord.
  • LN (Lower Ninth) — uses the flat 9th on the ii chord; the V chord uses the natural 5th (Type A) or flat 13th (Type B, to avoid a stack of thirds). The i chord resolves to a minor-major 7th chord.
  • R (Root) — replaces the 9th on the ii chord with the chord root. The V chord uses the natural 5th or flat 13th (both are shown as 5/b13). The i chord resolves to a minor 6th chord.
Grids (1–12)

Sets how many ii-V-i grids to display. Each grid represents a complete minor ii-V-i progression in a new key. Use the + and − buttons to add or remove grids. With more than one grid, connectors appear between grids showing how each voice moves from the i chord of one key to the ii chord of the next.

Grid Connection — interval & direction

Sets the interval between consecutive starting keys. Options: Half step, Whole step, Minor 3rd, Major 3rd, 4th, 5th, Minor 6th, Major 6th. The ↓ Down and ↑ Up toggle sets whether each new key is lower or higher than the previous one. Defaults to down.

Reading the voicing grids

Each grid shows the ii, V, and i chords for one minor key. Notes are displayed top to bottom within each column — the top note is the highest pitch (finger 5), and the red bottom row is the lowest note (finger 1 / thumb). The small label beneath each note shows its function in the chord (e.g. b3, b7, 9).

When a voice shows 5/b13 as its label, the note name shows both options — e.g. B/C on an E7 chord. Both are valid; the flat 13th adds more colour.

A Type A or Type B badge appears next to each grid label so you always know which voicing type is in use.

Type A / B switching rule

This rule comes directly from JPF Book 1 (p. 94). When moving from one key to the next:

  • Half step or whole step — keep the same type. Step motion creates smooth voice leading without switching.
  • Minor 3rd or larger — switch type (A→B or B→A). Larger intervals need alternation for smooth voice leading.

The app applies this automatically. A green "type stays" or amber "type A↔B" badge appears on each connector and in the controls row.

Connectors — i → new ii voice leading

Between grids, a connector shows how each of the four voices moves from the i chord of one key to the ii chord of the next key. Each box shows the finger number, the note it leaves, the note it arrives at, and the direction and size of the move:

  • ↑ green — voice moves up
  • ↓ red — voice moves down
  • = grey — voice stays on the same note
  • amber — large leap (4th or more)

The connector uses real octave-aware MIDI positions so directions are always physically correct — a voice shown moving up actually moves up, even for large intervals like a 5th.

Finger movement panel

The panel at the bottom summarises the right-hand fingering for the three chord movements within a single ii-V-i:

  • LH — finger 1 plays the root, finger 5 plays the fifth.
  • ii → V — Type A: fingers 1 and 2 stay; fingers 3 and 5 each drop a half step. Type B: fingers 1 and 2 each drop a half step; fingers 3 and 5 stay.
  • V → i — All voices descend: fingers 1 and 3 each drop a whole step; fingers 2 and 5 each drop a half step.
  • i → new ii — See the connectors between grids. Movements depend on the selected interval and whether the type switches.

The LH upper voices box at the bottom shows the left-hand fingering when playing the voicing in the left hand: 5-4-2-1 for the ii chord and 5-3-2-1 for the V and i chords (or reversed for Type B).

Download print sheet

The "Download print sheet — all 12 keys" button generates a single-page reference sheet showing the current configuration across all 12 starting keys in a 3-column grid. The file downloads as minor-251-all-12-keys.html. Open it in any browser and print or save as PDF. The config summary (type, formula, grids, interval, direction) is printed at the top of the sheet.

Magic range / ideal register

The red bottom note of each voicing should fall between C3 and C4 (the octave below middle C). This is the "ideal register" from JPF Book 1 p. 88. If the bottom note drifts too low, use the typewriter-jump technique: flip voicing type (A↔B) or move up an octave to stay in range.
